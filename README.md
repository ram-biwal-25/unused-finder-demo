# unused-finder-demo

A demonstration project showcasing [unused-finder](https://www.npmjs.com/package/unused-finder), an npm CLI tool for identifying potentially unused dependencies and assets.

## Purpose

This repository intentionally contains unused dependencies and assets to demonstrate the detection capabilities of `unused-finder`.

## Test Cases

- **axios** – used dependency
- **lodash** – intentionally unused dependency
- **used-logo.png** – referenced asset
- **unused-logo.png** – intentionally unused asset

## Installation

Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/unused-finder-demo.git
cd unused-finder-demo
npm install
```

## Run the Demo

```bash
npx unused-finder
```

Follow the CLI instructions if additional arguments are required.
